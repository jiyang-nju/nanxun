# 南寻 · NJU Guessr

**你走过的南大，还认得吗？**

一个看照片、在地图上猜位置的南京大学校园小游戏。第一版从鼓楼北园开始：5 张真实校园照片、地图落点、距离评分、逐轮揭晓和可下载的成绩卡。

## 本地运行

需要 **Node.js 22.18+（推荐 24 LTS）** 和 **pnpm 11.19.0**。

```sh
corepack enable
corepack prepare pnpm@11.19.0 --activate
pnpm install
pnpm dev
```

若当前 Node 安装不带 Corepack，可用 `npm install -g pnpm@11.19.0` 安装 pnpm。

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。

```sh
pnpm test       # 计分、距离、随机题组、地图边界测试
pnpm build      # TypeScript 检查及生产构建
pnpm preview    # 本地预览 dist 构建
pnpm format     # 统一代码格式
```

开发环境目前仅绑定本机。若要用同一局域网内的手机试玩，运行 `pnpm dev --host 0.0.0.0`，用电脑局域网 IP 加端口访问。不要将开发服务器直接暴露到公网。

## 已实现

- 鼓楼北园 5 站：北大楼、大礼堂、东大楼、革命烈士纪念碑、西大楼。
- 照片放大、可开关的文字提示。
- 本地 SVG 校园示意图：点击选点、拖动、放大缩小、重置视野。
- 键盘选点：地图获得焦点后按方向键移动，Shift 加速，Enter 在初始位置落点。
- 每轮最高 5,000 分；20 m 容差范围内满分，距离越远分数越低。
- 逐轮答案连线、5 轮总结、称号、本机最高分。
- 在浏览器内生成 PNG 成绩卡；重新开始时打乱题目顺序。
- 手机和电脑布局、原生可关闭模态框、图片加载失败重试。

无需后端、登录、地图 API Key 或模型 API。运行中的照片和地图不依赖第三方服务。

## 照片与地图说明

**当前 5 张照片来自南京大学「南大风华」，仅作本地开发样例；公开发布前请替换为自己的照片或已获授权的素材。** 来源、转换方式及原图 URL 见 `src/data/credits.json`、页面“照片与地图来源”和 [素材说明](docs/ASSETS.md)。仓库没有为这些照片授予开放使用许可。

地图参考南京大学资产管理处公开的 2024 年鼓楼校区平面图，手工绘制了北园相关道路与建筑的简化示意。它不是测绘地图或 GPS 导航，`METERS_PER_UNIT = 0.8` 仅为游戏距离估算参数。位置和形状需要实地校准，分数不表示精确的真实空间误差。

题目答案是 **照片中建筑/地标的位置**，不是拍摄者所在位置。

## 换成自己拍的照片

见 [题库维护指南](docs/QUESTION_BANK.md)。下一步最有价值的工作是实地拍摄更多角度、标定地标坐标，然后将题库扩充到 20 张。

## 第一版的边界

- 5 张入门样例，首次打开按固定顺序出题，重玩打乱顺序。
- 最高分只保存在当前浏览器；刷新会重开本局。
- 分数和答案均在客户端，适合朋友间练习，不作为防作弊排行榜。
- Vite 的 `base: './'` 支持静态子目录，完成照片授权或替换后可将 `dist/` 发布到静态托管服务。
- 本次仅构建本地项目，未推送远端、未发布线上网站。
